# A02 — interview placement recommendation

Assigned to: Astra. Module: admissions-placement. Status: queued. Depends on: U01.

## Owner policy

After an admission interview is complete, the system recommends placement using
approved location, age, class, active group availability, and balancing rules.
An authorized person reviews the recommendation and may rebalance it before a
real group assignment is written. A mid-batch joining participant bypasses this
recommendation flow and is placed directly through U01 by an authorized user.

## Boundary

Automatic placement is a deterministic recommendation, never an unreviewed
attendance-enrolling action. It must explain its rule inputs, avoid names/phone
matching, preserve a manual override audit record, and deny an incomplete scope.
The rule configuration, source-field mapping, capacity policy, interview state,
and placement-review UI are defined only after U01's nullable-group backend is
accepted.

No production data read/write, import, migration, deployment, or UI work is
authorized by this queued task.
