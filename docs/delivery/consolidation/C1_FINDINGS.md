Verify inactive, missing, contradictory, foreign-city and foreign-park/group cases with real scoped fixtures.

**C1-F02 — both branches can overbook; v2 direct check-in bypasses capacity and safety requirements.** `v2:src/app/api/events/[id]/registrations/route.ts:198–242` checks count before upsert; `action=check_in` skips the capacity branch. Correction: serialized/atomic reservation, retry identity and explicit lifecycle eligibility; direct check-in must validate an existing eligible registration. Native SQLite/PostgreSQL concurrent-client verification is required in C2.
